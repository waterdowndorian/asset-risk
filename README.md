# 배전설비 위험도 자산관리 · 설비 위치

asset.power.pe.kr 운영 화면과 동일한 index.html을 기준으로 왼쪽 메뉴에 **설비 위치**를 추가했습니다. 상단 왼쪽 아이콘과 브라우저 탭 아이콘에는 제공된 PNG를 사용합니다.

## 로컬 확인

압축을 모두 풀고 index.html을 엽니다. **설비 위치**에서 시연용 가상 좌표를 볼 수 있습니다.

도로 배경지도를 확인하려면 압축을 푼 폴더에서 아래 명령을 실행하고 브라우저에서 http://127.0.0.1:8000/을 엽니다. Windows에서 `py` 명령을 사용할 수 없으면 `py -3` 대신 `python`을 사용합니다.

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

배경지도는 인터넷 연결이 필요합니다. 기존 사이트의 브라우저 저장 데이터는 같은 사이트 주소에서 이어서 열 수 있습니다. 로컬 주소에서 사용하려면 운영 사이트의 **데이터 통합 → 전체 백업**으로 JSON을 내려받고 로컬의 **백업 복원**을 사용합니다.

## 좌표 입력

**데이터 통합 → 자산정보** 파일에 선택 열 `lat`, `lon`을 추가합니다. WGS84 십진도 기준 위도·경도이며, 열 연결 창에서 각각 매핑할 수 있습니다. 두 좌표를 입력한 설비는 점으로 표시합니다. 한 좌표만 입력했거나 범위를 벗어났으면 품질 화면에 표시되며, 좌표 상태는 위험도 평가 산식에 영향을 주지 않습니다.

대시보드에서 설비명을 눌러 상세를 연 뒤 **지도에서 보기**를 사용합니다. 지도에서 마커를 눌러 해당 설비의 요약 지표를 확인하고, **순위표에서 보기**로 돌아갈 수 있습니다. 지도와 대시보드는 설비 검색, 유형, 위험도 등급 필터를 공유합니다.

지도에는 Leaflet 1.9.4와 OpenStreetMap 배경지도를 사용합니다. 지도 타일 요청에는 화면 범위에 해당하는 타일 번호가 사용됩니다.
